# Global vs Arabic/MENA — Comparative Reference

What actually differs, side by side. Use when designing bilingual or
localizing an existing product.

| Dimension | Global (EN-first) norm | MENA/Arabic norm | Confidence |
|---|---|---|---|
| Direction | LTR | RTL (but charts/numbers LTR) | HIGH |
| Typography | 1–2 Latin families | Latin + Arabic pairing decision; larger sizes, taller line-height | HIGH |
| Type identity | Proprietary display faces for brand | Kufi display energy or institutional faces (Dubai font); Naskh for reading | MEDIUM |
| Density | Airy on premium, dense on utility | Similar split; MENA portals tolerate higher nav/link density (OBSERVED stc 612 links) | MEDIUM |
| Navigation | Left logo, right actions | Mirrored; language toggle top-level always | HIGH |
| Search | Autocomplete + facets | Same + bilingual matching, Arabic normalization, transliteration tolerance | HIGH |
| Cards | Image-led, consistent ratios | Same mechanics; badges/flags localize; price blocks with Arabic currency labels | HIGH |
| Forms | Labels above, validation inline | Same + LTR data fields inside RTL pages, country-code selectors, district text areas | HIGH |
| CTA voice | "Get started" verb+object | ابدأ مجاناً register-aware; formal plural for conservative brands | MEDIUM |
| Mobile | Bottom tabs, sticky CTAs | Same + higher Android/budget-device share → perf floor stricter | HIGH |
| Payments | Cards/wallets (Apple/Google) | + COD, mada, STC Pay, Fawry, KNET, BNPL logos pre-checkout | HIGH |
| Trust marks | Reviews, press logos, security seals | + regulator/ministry logos, WhatsApp number visible, Islamic-finance markers | HIGH |
| Dates | Gregorian | Gregorian + Hijri where relevant; Arabic month names per market | HIGH |
| Numbers | Western digits | Western digits dominate data/prices; Arabic-Indic in formal EG/gov content | MEDIUM |
| Currency | $ / € decimal 2 | SAR/AED/EGP; KWD 3 decimals; label after amount | HIGH |
| Social proof | Individual testimonials | Family/community endorsement resonates; named+photo still king | MEDIUM |
| Seasonality | Black Friday, Christmas | Ramadan/Eid (night traffic peaks!), White Friday (regional BF), national days | HIGH |
| Support | Chat/email/ticket | WhatsApp-first with visible number | HIGH |
| Video | Sound-off autoplay | Same + Arabic subtitles/captions expected on quality content | MEDIUM |
| Empty states | Friendly illustration + action | Same craft; illustrations must respect dress/modesty per market | MEDIUM |
| Performance budget | LCP 2.5s 4G | Stricter: budget-Android heavy market, 3G pockets | HIGH |

## Localization maturity ladder

1. **Direction-flipped** (minimum, often broken: unflipped icons, LTR
   buttons) — NOT "Arabic UX"
2. **Translated**: full MSA copy, correct punctuation, real Arabic type
3. **Localized**: payments/dates/currency/district addressing, WhatsApp,
   bilingual search, Hijri awareness
4. **Culturally native**: dialect-aware voice, seasonal IA (Ramadan hubs),
   regional trust marks, market-specific imagery, per-market numerals
   policy

Aim ≥3 for commercial products; 4 for market leaders.
