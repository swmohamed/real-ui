# Redesign Preservation (identity survives evolution)

A redesign that destroys useful product identity without reason fails —
users lose their product. Default: **the same product evolved.**

## Preserve unless a diagnosed problem justifies change

| Preserve | Why | Sacrifice only if |
|---|---|---|
| Brand personality & recognition (logo, signature color, mascot, voice) | recognition = trust already paid for | rebrand explicitly requested |
| Working workflows & shortcuts | muscle memory is real cost | flow is provably broken |
| User terminology | users search/think in these words | labels tested as confusing |
| Valuable information structure | retraining cost, SEO | IA provably wrong |
| Important behavior (shortcuts, offline, notifications) | silent regressions anger | replaced by better equivalent |
| Community/customization artifacts | users' work lives there | migration path exists |

## Recognition tests (cheap, do them mentally)

1. **5-second test** — returning user glances at new home: still knows
   which product this is?
2. **Wayfinding test** — can a returning user still do their top task
   without relearning?
3. **Blind-lineup test** — new design among competitors: identifiable
   without reading the logo?

If all three fail, the redesign is a rebrand nobody ordered.

## The evolution dial

| Mode | When | Identity change |
|---|---|---|
| Refresh | visual system decayed, UX works | typography/spacing/color system; structure intact |
| Modernization | UX frictions + dated visuals | new components, flows improved, brand constants kept |
| Rework | wrong IA/platform mismatch | structure changes, brand constants kept |
| Transformation | explicit request / rebrand | everything negotiable (workflow.md "transformation mode") |

## Regression ledger (transparency artifact)

For any non-trivial redesign, output a table: KEPT / CHANGED / REMOVED /
MERGED / ADDED — each with one-line reason. Users can audit what they
lost. This is also your defense against "AI slop redesign" accusations:
every change has a name and a reason.
