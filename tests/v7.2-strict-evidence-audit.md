# V7.2 Strict Evidence Audit

Date: 2026-09-03. Trigger: user-mandated strict audit before push.

## What the audit found

The V7.1 ledger (533 refs) was a MIXED pool: real fetched products +
module-observed names + V7 DOC studies. Recounted strictly (only
fetch-retained real production products, deduped by normalized name,
one entry per product, each traceable to a retained record with requested
URL + final URL + extracted structure evidence):

- 18 of 24 categories were BELOW the 20-real-product floor once
  non-product sources were excluded (e.g. ecommerce 8, healthcare 11,
  gaming 11, b2b 12, immersive 11).
- The v7.1 report's PASS table was therefore invalid; it is superseded
  by this audit.

## Remediation

1. `research/tools/evidence_ledger.py` rewritten to STRICT mode:
   products vs supporting sources counted and reported separately;
   per-product traceability rows (name / URL / final URL / region+lang /
   observed-structure summary / source wave).
2. Waves 9a+9b (146 candidates) and wave 10 (33 candidates, targeted at
   remaining shortfalls; alternates swapped for bot-walled products).
   131 new SOURCE-OBSERVED products retained, prioritizing missing
   product models, regions, and audiences:
   - resale marketplaces (stockx-class, vestiaire, poshmark, vinted),
     regional marketplaces (noon GCC, jumia Africa, mercadolibre LatAm,
     alibaba B2B)
   - telehealth visit-flow pages (teladoc, livi), symptom-checker (ada),
     drug-cost (goodrx), MENA teletherapy (shezlong)
   - console portals (playstation, nintendo, blizzard) vs instant-play
     grids (poki, crazygames, kongregate, gamejolt)
   - delivery-discovery (talabat, openrice, swiggy, zomato)
   - modest fashion (modanisa), beauty DTC (glossier, mac), sportswear
     verticals; gov portals (govt.nz, india.gov.in, gov.pl, gov-online
     jp); immersive (activetheory, unit9, flourish, rawgraphs,
     explorables, seeingtheory, ncase, earth.nullschool, ventusky)
3. Knowledge integrated: "Strict-audit additions (v7.2)" sections in
   ecommerce-marketplace, healthcare, gaming, restaurants-food,
   fashion-luxury-beauty (family logic: resale condition taxonomy,
   telehealth visit-flow-first, console-portal vs instant-grid split,
   delivery decision-trio cards, modest-fashion taxonomy-first nav,
   beauty usage-first interleave).
4. Permanent rule strengthened in research method: floor counts real
   products only; supporting sources stay separate; future upgrades add
   diversity, never mix classes.
